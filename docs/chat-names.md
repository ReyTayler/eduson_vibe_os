# Названия разговоров Eduson Kids

Состояние: 7 октября 2026. Реализовано и опубликовано на [рабочей платформе](https://80.249.145.94/).

В списке «Разговоры» у каждой строки есть отдельные кнопки с карандашом и искрами. Карандаш открывает ручное переименование; искры — подбор имени по истории. То же управление доступно рядом с выбором чата внутри проекта. В диалоге можно изменить вариант, добавить эмодзи и сохранить имя до 80 символов. Проект и дата остаются под названием. Закрытие окна с вариантом не меняет название.

## Автоматическое имя

Первый пустой чат получает имя проекта, следующие — имя проекта и номер. Первый принятый запрос сразу создаёт локальное название; небольшой отдельный вызов DeepSeek Flash уточняет его после завершения основной очереди Harness. В дальнейшей переписке название автоматически не меняется. Явно заданное при создании или вручную сохранённое имя имеет приоритет.

При первой миграции существующие имена «Первый разговор», «Новый разговор» и «Новый чат» считаются системными. Для чатов с сообщениями выбирается тема по первому запросу и последним двум уточнениям; пустые получают название проекта. Остальные старые имена сохраняются как ручные. Миграция не повторяется при следующем запуске. Схема старого кабинета не позволяла отличить вручную введённое «Первый разговор» от исходной заглушки; классификация этих трёх строк — явное ограничение миграции.

## API и данные

- `GET /api/projects/:id/chats` дополнен `name_source`, `name_revision`, `name_status`.
- `PATCH /api/chats/:id` принимает `name` и необязательный `nameRevision`. Новые клиенты передают версию, старые могут продолжать без неё. При конфликте возвращается 409 `CHAT_NAME_CHANGED`; окно сохраняет ввод и предлагает проверить имя, изменённое в другом окне. Запрос только с `reasoningMode` не фиксирует название как ручное.
- `POST /api/chats/:id/title-suggestion` с `{}` возвращает `{name, source, name_revision, reason?}`. Вариант становится названием только после отдельного сохранения. Четыре попытки в минуту на аккаунт; одновременно работает один вызов, одинаковые параллельные запросы объединяются.
- Три добавочных столбца `chats` хранят источник, версию и состояние. Версия меняется при принятии первого автоматического имени и ручном сохранении. Поздний результат фоновой модели применяется только при совпадении версии и источнике `auto`.

Действуют существующая сессия, CSRF и проверка владельца. Нельзя передать другой `student`, credential или capability. Broker выводит ученика из проекта. Название не включается в системный запрос Harness, а сообщения, курсор сессии, файлы и запуски не изменяются.

## DeepSeek и кредиты

Broker выполняет отдельную операцию `chat-title` через существующий закрытый `/v1/messages` model gateway. Используются `deepseek-flash`, `thinking.type: disabled`, без инструментов, максимум 128 выходных токенов **только для служебного названия**. Пределы ответа рабочего помощника остаются прежними. Ограниченный контекст содержит имя проекта, первый запрос и два последних уточнения; кодовые блоки, ключи, строки паролей, длинные секреты, адреса почты и ссылки исключаются.

Стоимость учитывается обычным личным кредитным журналом ученика с разбивкой кэша, входа и выхода. Вызов не проходит через операторский тестовый бюджет. Для занятой основной очереди, пустого чата, недоступного провайдера или нехватки кредитов используется локальное название. Подбор не нужен для начала основного запроса и не задерживает его в очереди. Краткий служебный вызов может уже выполняться, когда приходит новый запрос; gateway продолжает отдельно обслуживать основной Harness.

Таймаут 15 секунд, неполный поток, ошибка провайдера, обрезанный ответ или неподходящее имя приводят к локальному варианту. После перезапуска незавершённый платный подбор автоматически не повторяется. Проверка потока ограничивает память и требует `message_stop`. Стандартные гарантии учёта gateway сохраняются: подтвердившееся usage списывается, неопределённый вызов может удержать резерв.

## Исходники и проверка

`apps/portal/api/chat-names.mjs` — миграция, нормализация, очередь, версия и API подбора; `services/workspace-broker/chat-title.mjs` — закрытый клиент потокового gateway; `apps/portal/src/ChatNameActions.tsx` и `chat-names.css` — общие диалоги и кнопки.

18 офлайн-проверок БД, гонок, владельца, контекста и SSE: `node --test apps/portal/tests/chat-names.test.mjs`. Production build со strict TypeScript прошёл. Семь групп браузерных проверок кандидата выполнены с приватными перехватами в headless-браузере, без публичного стенда или обращений к модели. Ещё семь групп прошли на рабочей платформе, включая настоящий подбор, сохранение ручного имени, перезагрузку страницы, CSRF, чужой аккаунт, версию и мобильные экраны 390/320 px.

При выкладке основной очереди и вызовов модели не было. Перезапущены portal и broker, gateway продолжил работу; старые JS/CSS для открытых вкладок сохранены. Два реальных вызова названий (миграция и проверка предпросмотра) использовали суммарно 828 токенов и $0,000100968, отнесённых на student01. Таблицы users/projects/folders/messages/runs, идентификаторы/курсоры/reasoning чатов и все восемь файлов проектов совпали с резервным снимком. Намеренно обновлены только поля названия чатов.

Артефакты: `evidence/chat-names-tests.tap`, `chat-names-candidate-ui.json`, `chat-names-live-ui.json`, `chat-names-deploy.json`, `chat-names-final.json`; снимки в `evidence/portal-ui/chat-names-*`.
