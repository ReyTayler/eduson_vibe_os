# Vibe OS — ученические кабинеты

Рабочая платформа: **[https://80.249.145.94/](https://80.249.145.94/)**.

Разработка, сборка, данные и проверки находятся на сервере `80.249.145.94`. Репозиторий: `/opt/vibe-os/platform`, ветка `codex/vibe-os-poc`. На ПК исходники не создавались.

Созданы пять независимых кабинетов `student01`–`student05`. Пароли хранятся отдельно от репозитория в root-only `/var/lib/vibe-os/portal-private/student-logins.json`. При начальном заполнении у первого ученика два стартовых проекта, опубликованный сайт и настоящий разговор с DeepSeek. У остальных четырёх нет проектов и папок.

В каждом чате доступны рассуждения Off/Low/High/Max и вывод до 65 536 токенов за вызов. [Параметры и проверки](docs/reasoning-settings.md).

Работают проекты и папки, файловые директории, редактор, сохранение с контролем версии, выполнение Python/Node, отдельные чаты с реальным DeepSeek Harness, предпросмотр и включение/выключение постоянного хостинга. Одновременно доступны три опубликованных сайта на ученика. Интерфейс выполнен на React: голубой/белый, прозрачные панели, анимации и адаптация для телефона.

**Текущая публикация поддерживает HTML/CSS/JS.** Python и Node выполняются внутри кабинета с ограниченным временем; постоянный HTTP-процесс пользовательского backend пока относится к следующему этапу.

## Проверки

```sh
# Без платных вызовов; запускаются на сервере оператором.
node --test tests/model-gateway.test.mjs
python3 apps/portal/tests/acceptance.py
node apps/portal/tests/ui-first.mjs
node apps/portal/tests/ui-editor.mjs
node apps/portal/tests/lifecycle.mjs
node apps/portal/tests/secret-scan.mjs
```

Последние пять сценариев используют защищённые серверные реквизиты; на внешней машине их запускать не следует. Приёмка создаёт временные проекты и удаляет их, оставляя четыре кабинета пустыми. Сценарий lifecycle кратко отключает model gateway, проверяет отзыв сессий и восстанавливает исходный пароль пятого ученика.

`apps/portal/tests/live-ui.mjs` выполняет **платные** запросы. Уже прошёл; в обычный health check его не включать. Первоначальная проверка кабинетов использовала **3 135 токенов, 12 запросов**. Приёмка reasoning добавила **7 685 токенов, 8 запросов**. Общий актуальный расход, включая самостоятельную работу учеников, смотрите через operator status. Общая авторизация ограничена 1 000 000 токенов и не сбрасывается после перезапуска.

Артефакты проверок и снимки интерфейса: `evidence/`. Старые демосервисы отключены, их данные и результаты сохранены для аудита. Их lifecycle tests относятся к историческому стенду и сейчас требуют отдельного восстановления fixtures.

Bootstrap пока состоит из отдельных скриптов и настроек конкретного сервера, полного переносимого production installer нет.
